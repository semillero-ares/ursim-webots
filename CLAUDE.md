# CLAUDE.md — ursim-webots Documentation

## Project Overview

This is the **documentation branch** (`docs`) for the [ursim-webots](https://github.com/semillero-ares/ursim-webots) project by **Semillero ARES** at Universidad EAFIT. It contains a MkDocs-based tutorial in **Spanish** that teaches users how to simulate Universal Robots collaborative arms using URSim (via Docker) and Webots.

- **Live site:** https://semillero-ares.github.io/ursim-webots/
- **Author:** Davinson Castaño Cano

## Common Commands

```bash
# Install MkDocs (one-time)
pip install mkdocs

# Local preview with live reload
mkdocs serve

# Build static site
mkdocs build

# Deploy to GitHub Pages
mkdocs gh-deploy
```

## Content Conventions

- **Language:** All content is written in **Spanish**.
- **File naming:** Pages are prefixed with numbers (`10-`, `20-`, `50-`, etc.) to control sidebar order.
- **Images:** Use the MkDocs `attr_list` extension to add CSS classes:
  ```markdown
  ![alt text](img/path.png){: class="img-center" title="Caption"}
  ![logo](img/logo/x.svg){: class="logo img-center" title="Logo"}
  ```
- **CSS classes defined in `extra.css`:**
  - `.logo` — constrains logo images to max-width 100px
  - `.img-center` / `p:has(.img-center)` — centers images via parent paragraph
- **Brand colors:** `#146aef` (primary) → `#000086` (dark), used in the sidebar nav gradient.
